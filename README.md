# Boyfriend Birthday Website — Cinematic V2

This version is intentionally not a generic clean birthday template. It uses a cinematic, story-driven structure inspired by current interactive birthday-site patterns: private PIN entry, a dramatic opening, gift reveal, memory wall, timeline, envelope letter, personal question, and a final celebration.

Flow:
1. index.html — 8-digit secret PIN
2. intro.html — cinematic typewriter opening
3. gift.html — interactive gift box
4. memories.html — editorial photo wall
5. story.html — scrolling story
6. letter.html — physical-style envelope reveal
7. secret.html — personal mini-question
8. final.html — cake + birthday reveal + confetti

Password is already `27102007`.

To personalize:
- Replace photo placeholders with your photos.
- Change the text directly in each HTML file.
- Change `birthdayName` in js/config.js.
- Add your music later; browser autoplay rules mean the song should start after a user tap.
- The PIN is a front-end surprise lock, not real security.
